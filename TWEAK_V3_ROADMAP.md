# PWStudy Tweak — V3 Advanced

This is an experimental development branch based on pwstudy-daily-2026-11-22. Do not merge into main without successful build and regression testing.

## Priorities
1. Fix PDF open, pinch zoom and pan in all directions.
2. Fix video landscape crashes and player lifecycle.
3. Add PDF annotations, offline library organization and chapter indexing.
4. Improve settings, theme and home-screen customization.
5. Preserve authorized Telegram channel access without exposing full Telegram navigation.
6. Run Android CI, smoke tests, and compare APK sizes.

## Size policy
90–120 MB is an illustrative upper target, not a minimum. Do not add padding or unnecessary dependencies to inflate APK size.

## Release policy
Keep existing features functional; no merge to main until tests pass.
